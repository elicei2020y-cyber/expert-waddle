# Симбиоз: отмотка порождения на настоящей модели

Проверяющий код читает выдачу языковой модели по мере порождения. Найдя
дефект, он отматывает порождение назад и перепорождает с пометкой: что
отозвано и почему. Здесь проверяется, работает ли это на настоящей
модели (Qwen2.5-0.5B на процессоре), а не только на игрушке.

- `CLAUDE.md` — правила работы (читать первым).
- `ZADANIE.md` — задание З-8.
- `PREDICTIONS.md` — предсказания, записанные до прогона.
- `docs/igrushka_rezultaty.md` — эталонные результаты игрушки.
- `igrushka/` — игрушечная модель и опыты с ней (эталон, не менять).
- `qguard/qguard.py` — рецепт квантования весов.

Быстрая проверка: `python3 igrushka/proverka.py` → «совпало».
