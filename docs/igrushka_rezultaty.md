# Результаты игрушки — эталон для сравнения

**Подложка.** Маленькая символьная модель (`igrushka/lab/model.py`,
веса в `model.npz`) выдаёт статистический отчёт по полям: n df M sd se t
p d. Поля идут по очереди, испорченное значение попадает в контекст всех
следующих. Дефекты наводятся квантованием её весов. 60 отчётов. Проверка
— код: отношения между полями (df = n − 1, se = sd/√n, t = (M − mu)/se и
т. д.).

Язык и смысл игрушка не проверяет. Проверяется механика: как ошибка
распространяется и сколько стоит отмотка.

## Две линии — `igrushka/opyty/fork/fork.py`

При дефекте порождение раздваивается: одна ветвь отматывается, другая
продолжает с ошибкой.

**4 бита**

| политика | верных из 8 | ровно 8 | молчание | перепорожд. |
|---|---|---|---|---|
| не вмешиваться | 7.52 | 53 | 0 | 0.00 |
| отмотка на 1 шаг, БЕЗ пометки | 7.52 | 53 | 0 | 1.50 |
| отмотка на 1 шаг, с пометкой | 8.00 | 53 | 7 | 0.00 |
| отмотка к происхождению, с пометкой | 7.70 | 53 | 4 | 0.16 |

**3 бита**

| политика | верных из 8 | ровно 8 | молчание | перепорожд. |
|---|---|---|---|---|
| не вмешиваться | 5.27 | 21 | 0 | 0.00 |
| отмотка на 1 шаг, БЕЗ пометки | 5.27 | 21 | 0 | 8.25 |
| отмотка на 1 шаг, с пометкой | 8.00 | 22 | 38 | 0.05 |
| отмотка к происхождению, с пометкой | 6.12 | 23 | 26 | 1.24 |

«Верных из 8» считается по выданным отчётам: молчание его завышает.
Честнее смотреть на «ровно 8» и «молчание».

**Выводы игрушки:**
1. **Отмотка ничего не портит.** Верное остаётся верным.
2. **Спасает мало:** 21 → 22–23 полностью верных при 3 битах, то есть
   1–2 из 39 неверных.
3. **Покупает молчание:** 26–38 отчётов не выдано. Это механизм
   воздержания, а не исправления.
4. **Без пометки отмотка — чистый расход:** тот же результат знак в
   знак при 1.5–8.25 лишних перепорождения. Контекст тот же, выбор
   детерминирован.
5. **Глубина по графу зависимостей:** 26 молчаний вместо 38.

## Засорённый контекст — `polluted.py`

Проверка видит 87% неверных полей. Медианное опоздание — 0 шагов,
максимум 5. Если в контексте уже есть подменённые поля, отмотка только
своего поля не помогает (1.93 верных из 8). Отмотка в засорённое тоже —
6.43 верных, но 25 молчаний.

## Богатство журнала — `record.py`

Когда журнал действий покрывает 5 и больше полей из 8, обнаружение
100%, без опоздания. При 0–4 полях — неровно, от 0% до 67%.

## Чего игрушка НЕ проверяет

Понимает ли модель пометку. Для игрушки пометка — просто символы. Ради
этого и нужен опыт на настоящей модели.

**Расхождение, о котором надо знать:** в одном прежнем документе
перепорождения для отмотки с пометкой при 3 битах указаны как
1.95 / 1.93. `fork.py` печатает 0.05 / 1.24. Эталон — вывод `fork.py`.
